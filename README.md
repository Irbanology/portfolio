# Irban Portfolio

A dark, futuristic React + Vite portfolio built with JavaScript (no TypeScript).

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/main.jsx` to change:
- name / bio
- email
- GitHub and LinkedIn links
- projects
- skills
- experience

Replace `your@email.com` and the `href="#"` social links before publishing.
